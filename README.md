# Ashwanth A — Portfolio

Personal portfolio website for **Ashwanth A**, a Computer Science and Engineering student interested in front-end development and building useful web experiences.

## Built with
- HTML5
- CSS3 (responsive layouts and custom styling)
- JavaScript (mobile navigation and dynamic footer year)

## Sections
- Introduction and internship availability
- About
- Skills and tools
- Selected projects
- Student community experience
- Contact and social links

## Run locally
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Customize
Update the project cards as projects are completed, add project demo links, and replace any placeholder project visuals with screenshots of your own work.
